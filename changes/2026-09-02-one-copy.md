# 2026-09-02 — One copy of the serde vector and the scraped docs

Ratification: not required. No fixture, golden, spec row, or rule changed;
this entry records a housekeeping change to where the reference
implementation reads two inputs, so the dual-landing rule is not applied to
them by mistake.

## What changed

- `lm15-python/conformance/serde/canonical.json` (a mirror of
  `serde/canonical.json` here) is deleted. `check_serde_fixtures.py` and
  its pytest wrapper read this repository's file through
  `conformance/sources.py` (`LM15_CONTRACT_DIR` overrides the checkout
  location; the pytest wrapper skips when the checkout is absent, as
  `test_vet_shim.py` already did). The dual-landing rule from
  `2026-06-09-initial-migration.md` no longer applies to the serde vector;
  it still applies to `cases/`, `bodies/`, and `errors/` until the harness
  cutover.
- `lm15-python/conformance/provider_docs/` (three pages copied from the
  curl-fixtures scrape, no refresh script, drifted for four months before
  `2026-09-01-provider-refresh.md` noticed) is deleted. `check_doc_drift.py`
  reads `lm15-contract/scrapes/<provider>/pages/` next to the
  `update.sh` scrapers (`LM15_API_REFERENCES` overrides).
- The scrapers themselves now fail loudly: a shared `fetch.sh` writes a page
  only on HTTP 200 with a body, keeps the cached copy otherwise, and exits 1.
  Eighteen pages had rotted to the literal "Not Found" (11 OpenAI guides,
  6 Anthropic reference pages, 1 Gemini page); all are re-pointed and
  re-fetched, except Anthropic `getting-help`, which no longer exists in the
  docs index and is dropped. curl-fixtures commit `1af43bf` — unpushable,
  that repository turned out to be archived; the scrape moved to `scrapes/`
  the same day (`2026-09-02-receipts-and-scrapes-home.md`).

## Why

Two copies of one fact is the failure mode this repository exists to
prevent; the copy nobody refreshes is the one that lies. The serde direction
of the harness already tested the reference against this file; the mirror
only added a place to forget.

## Evidence

- lm15-python `773db53`: 948 tests green; `conformance/run_all.py --strict`
  green with both readers pointed at their single source; the two pytest
  wrappers skip cleanly with the overrides pointed at a missing path.
- Harness 13/13 directions green at lm15-python `773db53`.
