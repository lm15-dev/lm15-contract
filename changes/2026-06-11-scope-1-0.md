# 2026-06-11 — spec/SCOPE.md: the 1.0 freeze boundary

Decision (maintainer delegation): created spec/SCOPE.md defining the 1.0
freeze:

- FROZEN: the chat core — canonical types, serde, errors, request building,
  response parsing, streaming (the five harness directions).
- PROVISIONAL (may change in 1.x, additive intent): non-chat endpoints
  (embeddings/files/batch/image/audio) and live sessions.
- OUT OF SCOPE for 1.0: `gemini.cached_content` (cache-creation side channel
  the pure build/parse contract cannot express) and `openai.computer_use`
  (provider-executed computer use pending a future part type via MAP-1's
  amendment path).
- Post-1.0 policy: the frozen surface changes only additively, enforced by
  the surface ratchet (tools/audit.py) and tools/spec_drift.py.
