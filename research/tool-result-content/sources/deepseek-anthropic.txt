<h2 class="anchor anchorWithStickyNavbar_YAqC" id="anthropic-model-mapping">Anthropic Model Mapping<a href="#anthropic-model-mapping" class="hash-link" aria-label="Direct link to Anthropic Model Mapping" title="Direct link to Anthropic Model Mapping">​</a></h2>
<p>When you use the Anthropic API, we map the Claude model names you pass in:</p>
<ul>
<li>Models starting with claude-opus are mapped to deepseek-v4-pro</li>
<li>Models starting with claude-haiku or claude-sonnet are mapped to deepseek-v4-flash</li>
</ul>
<p>With this mapping, when using the developer mode of the new Claude Desktop APP, you can bypass the APP&#x27;s model name restrictions by simply changing the base_url and api_key to connect to DeepSeek models.</p>
