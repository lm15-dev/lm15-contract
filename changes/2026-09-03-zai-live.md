## Why this provider

lm15 shipped a `zai` compat preset that no one could route to and no one
had tested.  It sent Qwen's `enable_thinking`; Z.AI's wire is
`thinking: {type}` + `reasoning_effort` (the DeepSeek shape).  The research
source said so; the code and a test pinned the wrong shape.  This entry
replaces the guess with receipts.

## Two silent cells → two refusals (MAP-8)

- `tool_choice`: docs say auto only.  Live: `required` with one tool and
  "Say ok." → HTTP 200, plain text, no call (`probe-tool-choice-required`);
  `none` with a weather question → HTTP 200, **called the tool**
  (`probe-tool-choice-none`).  New compat field
  `OpenAIChatCompat.forced_tool_choice: "send" | "reject"`; the `zai` preset
  rejects, so every non-auto form raises `UnsupportedFeatureError` at
  `build_request`.
- `response_format.type=json_schema`: live HTTP 200 with markdown-fenced
  JSON carrying keys the schema never named (`probe-json-schema`).  New
  compat field `OpenAIChatCompat.json_schema: "send" | "reject"`; the `zai`
  preset rejects.  DeepSeek needs neither: it answers 400 (loud) — the
  knob exists for the silent server, not the loud one.

Both are pinned as build-time raises with `expect_lm15.raises`, the
mechanism from `changes/2026-09-02-map8-raises-pinned.md`.

## The error that changed a mapping

First attempt on an unfunded account: HTTP **429**, code `1113`
"Insufficient balance or no resource package"
(`receipts/2026-09-03-zai/NOTE-2026-09-03T01-40Z.md`).  The reference
mapped it to `RateLimitError` — retryable — so a client would have retried
a drained balance forever.  Code `1113` now maps to `BillingError` in the
Chat Completions error mapping, next to OpenAI's `insufficient_quota`.
Pinned as `zai.insufficient_balance` in `errors/cases/zai.json` with three
more envelopes (401 code `"401"`, unknown model 400 code `1214`, bad effort
400 code `1210`).  Stated trade-off: one provider's numeric code sits in
the dialect-wide table; a per-provider error table is the right home once
a third provider brings its own billing code.

## Decisions closed by the wire

| question | wire | decision |
|---|---|---|
| forced thinking on GLM-5.3 | explicit off → 400 `1210`; GLM-5.2 honours off | loud, no raise needed |
| effort words outside low/high/max | `medium`, `minimal` → 400 on 5.3 | verbatim pass-through stays (MAP-7) |
| `user` vs `user_id` | `user_id` validated (400 below 6 chars); `user` accepted, no echo | send `user_id` |
| reasoning_content required with tools? | 200 without it | `assistant_reasoning_content` stays default (DeepSeek's `include_empty` is not needed here) |
| temperature above the documented 1.0 | 1.3 → 200 | documented, not raised |
| cache usage | `prompt_tokens_details.cached_tokens` present; no hit on two identical 377-token prompts | parser unchanged |
